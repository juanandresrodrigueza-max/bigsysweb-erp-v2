## Para quién

Talleres, peluquerías, consultorios, servicios a domicilio: cualquier negocio que da turnos.

## Cargar y ver turnos

**Agenda → Nuevo turno**: cliente (o nombre y teléfono si es nuevo), profesional o recurso, fecha, hora, duración y servicio. La grilla muestra el día por profesional; se arrastra para cambiar de horario.

Estados: pendiente → confirmado → atendido, o cancelado / no vino. Los "no vino" quedan en la ficha del cliente.

## Recordatorios

Un día antes sale un WhatsApp al cliente con fecha, hora y dirección (si tenés la API de WhatsApp, solo; si no, te deja el mensaje listo para mandar). El cliente puede confirmar desde el link.

## Cobrar desde el turno

Turno atendido → **Cobrar**: se factura el servicio (y los artículos que se usaron) y se registra el cobro en un solo paso. Sale ticket o factura según el cliente.

## Turnos por la web

Si activás reservas online en **Configuración → Tienda y canales**, tus clientes eligen día y hora desde un link o desde tu tienda, y el turno entra en la agenda.
