# BigSysWeb ERP · Atajos y trabajo sin mouse

## En todo el sistema

| Atajo | Qué hace |
|---|---|
| `Ctrl` + `K` (o `/` fuera de un campo) | Buscador global: clientes, artículos, comprobantes por número, proveedores, pantallas y acciones rápidas |
| `Alt` + `N` | Nueva factura |
| `Alt` + `P` | Punto de venta (comercio o minimarket) |
| `Alt` + `C` / `V` / `S` / `F` / `D` | Clientes / Proveedores / Stock / Fondos / Inicio |
| `?` | Abre el buscador con la ayuda de atajos |
| `Esc` | Cierra el buscador o el modal |

En el buscador global: flechas para moverse, `Enter` para ir.

## Factura sin mouse

1. `Alt` + `N` abre la factura nueva con el cursor listo.
2. Cliente: escribí parte del nombre o CUIT y `Enter`. Sin escribir nada aparecen los **clientes recientes**.
3. Artículo: escribí y `Enter`. Sin escribir nada aparecen primero **lo que ese cliente compró** y después **lo más vendido**.
4. Al elegir el artículo el cursor pasa a **cantidad** → `Enter` → **precio** → `Enter` agrega la fila siguiente y vuelve al buscador de artículos.
5. `Ctrl` + `Enter` emite · `Ctrl` + `S` guarda borrador.
6. *Repetir la última factura de este cliente* carga los ítems de su última factura con los precios de hoy.

## Punto de venta

| Atajo | Qué hace |
|---|---|
| `F2` | Vuelve al buscador (escaneá o escribí) |
| `Enter` en el buscador | Agrega el primer resultado (o el código de barras exacto) |
| `F9` | Cobrar / confirmar el cobro |
| `Esc` | Cierra el cobro |

El POS carga solo los favoritos y los más vendidos (abre en menos de un segundo); el resto se busca al escribir o con el lector.
